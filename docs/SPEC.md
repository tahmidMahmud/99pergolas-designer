# 99 Pergolas Custom Designer — Build Spec (v1)

Goal: a Pergolux-style custom designer (https://pergoluxshop.com/products/pergola-custom-design) for **99 Pergolas** (Addison TX, WordPress/Divi marketing site, lead-gen only, no cart) covering **all their products**: louvered pergolas (Lux / Prestige), solid-roof patio covers, carports (cantilever), per-side enclosures (screens, glass, shutters, privacy panels), standalone motorized patio screens, motorized indoor shades, and outdoor kitchens (lead module).

Research behind every decision is in `docs/research/` (`pergolux.md`, `99pergolas.md`, `competitors-and-tech.md`, `site-notes.md`, screenshots in `shots/`). Read the relevant sections before building.

## Non-negotiables
- **Real-time parametric 3D** generated in code (React Three Fiber). No glTF models. Louvers animate open/closed; "Show Dimensions" draws labels inside the 3D scene (so they appear in snapshots).
- **US units**: inches internally, ft + in in the UI (dropdowns + slider like Pergolux). Meters only inside the scene.
- **Live estimated price range** ("Estimated $X–$Y installed") that updates on every change, plus "0% financing from $N/mo O.A.C." and the disclaimer. Never a firm quote.
- **State in the URL** (shareable, like `?width=3000&length=…` on Pergolux) – ours in inches: `?p=pergola&line=lux&w=144&d=192&h=108&m=fs&roof=louv&fc=black&lc=black&sf=screen:95&sl=glass-frameless&led=1&rgb=0&rain=1&wind=0&fans=1&heat=2&ctl=app`.
- **Lead capture, not checkout**: "Get my free estimate" → posts `LeadPayload` to `/api/lead` → emails sales + customer with share link, snapshot PNG, PDF spec sheet. Field names map to the existing Contact Form 7 estimate form (see 99pergolas.md §4).
- **Brand**: dark `#171A18` / `#20241F`, bone `#F2F1EC`, brass `#B4863B` (deeper `#8F6A2B`), text `#22251F`, muted `#62655D`; headings **Archivo**, body **Instrument Sans** (Google Fonts); 14px radius; gold pill buttons with arrow; logo `https://99pergolas.com/wp-content/uploads/2026/07/logo-white.png`. Phone (682) 241-5877, info@99pergolas.com.
- **Embeddable**: runs standalone (design.99pergolas.com) and inside an iframe on a Divi page; fixed-height viewer, postMessage height bridge, UTM pass-through. Mobile: viewer on top (sticky, ~45vh), options below, sticky bottom price bar with CTA.
- **Performance**: frameloop="demand" except during louver/camera animation; dpr capped at [1, 1.75]; instanced louvers; < 60 draw calls; handle WebGL context loss.

## Shared contracts (already written — do not rename)
- `src/types.ts` — all domain types (`PergolaDesign`, `ScreensDesign`, `ShadesDesign`, `KitchenDesign`, `ViewState`, `Structure`, `Estimate`, `LeadPayload`, …).
- `src/state/store.ts` — zustand `useDesigner` with `design`, `view`, `patch`, `setSide`, `setView`, `setStep`, `setProduct`, and defaults.

## Module ownership (agents work in parallel; touch only your folder + the files listed)

### 1. `src/config/` — catalog, rules, pricing, URL (agent: catalog-pricing)
Files: `catalog.ts`, `rules.ts`, `pricing.ts`, `url.ts`, `presets.ts`, `index.ts`, tests in `src/config/__tests__/*.test.ts` (vitest).
- `catalog.ts`: lines (name, tagline, bullets, maxBayWidth/Depth, maxHeight, louverMaxAngle 105/90, blade pitch, post size 5.875", beam 7.5"x4.5" (Prestige) / 8"x5" (Lux), features gating: rgb+app+voice Lux-only by default), colors (`black` RAL 9005 `#1d1f1e`, `grey` RAL 7016 `#3b3f3e`, `white` RAL 9016 `#f4f3ef`, `bronze` RAL 8019 `#4a3f2f`, `custom`), fabrics (blackout/99/97/95/90/70/60 with shade/privacy/visibility ratings from the site), enclosures (label, description, max panel width, per-sqft price band), accessories, shade styles, screen mount surfaces, kitchen options, presets (10x10, 10x12, 12x12, 12x16, 12x20, 14x14, 14x20, 16x20, 20x20 — in inches).
- `rules.ts`: `computeStructure(design): Structure` — bays (split when a dimension exceeds the line's single-bay max: Prestige 13'1"×19'8", Lux 19'8"×22'11"; soft cap 40'×40' → engineeringReview), posts per mounting (freestanding 4 + intermediates at bay lines; attached: posts on front only + ledger; floating: front posts inset 24"; cantilever: posts on back only, depth ≤ 20'), louver axis (auto = shorter side of the bay), louver count = floor((inside span − 2 end gaps) / pitch), beam/blade sizes per line, roofAreaSqFt, overallHeight. `validate(design): ValidationMessage[]` — min 7'0" sizes, height 7'0"–9'10", back enclosures disabled when attached/floating, side wider than 16' → "split into two screens", Prestige with rgb/app → suggest Lux (warn), cantilever depth > 20' (error), custom color note, etc. `clamp(design)` to legal values. Also `limits(line, mounting)` for the UI sliders.
- `pricing.ts`: `estimate(design): Estimate` — model from 99pergolas.md §3.3: base rate per sq ft (Prestige 55/70/85, Lux 75/95/120 low/mid/high), minimum charge (9k/12k), solid roof rate (Prestige band × 0.8), cantilever +15%, floating +12%, extra bay +5%/bay, custom RAL +6%, two-tone +2%, height > 9' +5%, add-ons table (LED 800–2000, RGB 1000–2500, rain 300–600, wind 250–500, fan 600–1500 ea, heater 800–2000 ea, app hub 300–800), enclosures per sqft bands (screen 45–75 /sqft min 3500, panel 40–70, sliding shutter 60–100, bifold 70–110, framed glass 80–120, frameless 100–150), screens standalone (per opening sqft 45–75, min 3500), shades (per window by style: roller 350–900, zebra 400–1000, honeycomb 450–1100, roman 500–1200, shangri-la 600–1400, vertical 700–1600; motorized +250–450), kitchen (per linear ft 900–1800 + grill 1500–4000, fridge 800–2000, sink 600–1500). Round low/high to nearest $100; monthly = mid / 60 (0% O.A.C., 60 months). Disclaimer text from competitors-and-tech.md §E3. Pure, deterministic, no DOM.
- `url.ts`: `designToParams(design, view?)`, `paramsToDesign(URLSearchParams)` (tolerant: unknown → default, clamp), `shareUrl(design)`. Also `designToCF7Fields(design, site)` mapping to form 1643/1783 field names.
- Export everything from `src/config/index.ts`. ≥ 25 vitest tests (structure, posts, validation, pricing monotonic in size, URL round-trip).

### 2. `src/scene/` — 3D (agent: scene)
Files: `Viewer.tsx` (default export; props `{ className?: string }`; reads `useDesigner`), `PergolaModel.tsx`, `Louvers.tsx`, `Enclosures.tsx`, `Accessories.tsx`, `Dimensions.tsx`, `Environment.tsx`, `House.tsx`, `Ground.tsx`, `ScreensModel.tsx` (standalone screens: a simple wall with N openings, housing + fabric), `materials.ts`, `units.ts`, `snapshot.ts` (`captureSnapshot(): Promise<string>` data URL, exposed via a module-level ref registered by Viewer), `index.ts`.
- Must call `computeStructure()` from `src/config` (import `{ computeStructure, CATALOG }` from `'../config'`). Until that agent lands, write against the `Structure` type and a local fallback.
- Geometry: posts (box with chamfer, base plate 7.7" sq), perimeter beams with gutter lip (extruded profile), ledger when attached, louver blades (`InstancedMesh`, one 170 mm-class blade geometry, rotation = view.louverAngle, closed = 2° tilt toward gutter), solid roof = flat panel with 2" fascia, cantilever = back beam + two cantilever arms, inset "floating" posts slimmer. Enclosures per side: zip screen (housing box under beam + semi-transparent fabric plane dropped to 85% height, fabric color/openness → opacity), glass (thin transparent panes, frameless vs framed with mullions), sliding shutters (panel with horizontal slats), bifold (3 folded panels), fixed panel (louvered). LED warm strip under beams (emissive, only visible when hour ≥ 19 or always faint), RGB = animated hue strip along gutter, fans (hub + 3 blades, count distributed), heaters (black bars under beam near posts). Dimensions overlay with drei `<Line>` + `<Text>` ft-in labels for W, D, H when `view.showDimensions`. House wall (brick-ish textured plane + simple roofline) when attached/floating/cantilever(optional). Ground: pavers/concrete plane with soft contact shadows.
- Lighting: `Environment preset="city"` or a procedural sky (drei `Sky` + suncalc sun for Dallas 32.78,-96.8 at `view.hour`), one shadow-casting directional light = sun; louver shadow stripes on the ground are the hero visual. Night (hour ≥ 19): dim sky, LEDs glow, bloom optional (desktop only).
- Camera: `PerspectiveCamera` fov 40, `OrbitControls` (no pan on mobile, minPolar 0.2, maxPolar 1.5 so you never go under ground, zoom limits), auto-frame on size change; `frameloop="demand"` + `invalidate()` on store changes; animate louver angle with lerp.
- Materials: powder coat = `MeshStandardMaterial` roughness 0.55 metalness 0.15 (satin paint, NOT chrome). Tone mapping `NeutralToneMapping`.
- Export `Viewer` from `src/scene/index.ts`. Also export `captureSnapshot` and `fitCamera()`.

### 3. `src/ui/` — configurator UI (agent: ui)
Files: `App.tsx` at `src/App.tsx` (you own it), `src/index.css` (global theme), `src/ui/*`: `Layout.tsx`, `Header.tsx`, `ProductSwitcher.tsx`, `Stepper.tsx`, `PriceBar.tsx`, `steps/SizeStep.tsx` (presets + ft/in dropdown pair + slider per dimension, mounting cards with SVG icons), `steps/StyleStep.tsx` (line cards Lux/Prestige, roof type, frame+louver swatches, custom RAL input), `steps/RoofStep.tsx` (louver angle slider, sun/time slider, show-dimensions toggle, control remote/app, rain/wind), `steps/SidesStep.tsx` (per-side cards with enclosure type + fabric picker with shade/privacy/visibility bars like the site), `steps/ComfortStep.tsx` (LED/RGB/fans/heaters steppers with +$ ranges), `steps/ReviewStep.tsx` (spec summary, itemized estimate, share link copy, "Get my free estimate" + "Book a measure" buttons), `LeadForm.tsx` (modal; fields name/phone/email/zip/city/timeframe/notes/consent; posts via `src/lead/submit.ts` → `submitLead(payload)`), `ScreensConfigurator.tsx`, `ShadesConfigurator.tsx`, `KitchenConfigurator.tsx` (non-3D: live SVG/2D preview cards), `Toast.tsx`, `icons.tsx`, `ui.module.css` or plain CSS files.
- Import `Viewer` from `'../scene'`, `estimate`, `validate`, `computeStructure`, `CATALOG`, `PRESETS`, `designToParams`, `paramsToDesign`, `shareUrl` from `'../config'`, `submitLead` from `'../lead/submit'`. If a sibling module is not there yet, create a minimal typed stub in YOUR folder (`src/ui/_stubs.ts`) and swap to the real import when it lands — do NOT write into other folders.
- Layout: desktop = 58% sticky viewer card (rounded, bone background) left + scrolling options column right, with the price + CTA sticky at the top of the column (Pergolux-style). Mobile ≤ 900px: viewer sticky top 45vh, steps below, sticky bottom PriceBar. Under the viewer: toggles "Open louvers" (sets angle 0↔max) and "Show dimensions", "Day/Night" chip, "Reset view", "Snapshot".
- URL sync: on load `paramsToDesign(location.search)`; on change `history.replaceState` (debounced 150 ms). Validation messages shown inline (errors red, warns brass).
- Accessible: labels, keyboard nav, focus rings; all text real (no lorem).

### 4. `src/lead/` + `functions/` + embed/docs (agent: backend-embed)
